# DECIDE Engine

An open calculation engine for health economic (HEOR) models, written in Python. This repository contains the calculation engine (`src/`) and the DECIDE desktop app built on it (`app/`).

| Model type | Status |
|---|---|
| Decision tree | Unit-tested |
| Markov cohort | Double-checked against the DARTH time-dependent Sick-Sicker model (Alarid-Escobar et al., 2021) |
| Partitioned survival (PSM) | Double-checked against a published model (Cai et al., 2021) |
| Microsimulation | Double-checked against the DARTH Sick-Sicker model (Krijkamp et al., 2018) |
| Network meta-analysis (frequentist, Bayesian) | Experimental |
| Budget impact (BIA) | In development |
| DES | In development |
| DynaTrans | In development |
| ABM | In development |

## Download the app

Prebuilt DECIDE apps for macOS (Apple silicon) and Windows are attached to the [Releases](../../releases) of this repository.

The apps are not code-signed, so the first launch needs one extra step:

- **macOS:** open the `.dmg` and drag DECIDE to Applications. Open DECIDE once; macOS will say it cannot be opened. Then go to **System Settings → Privacy & Security**, scroll down to the message about DECIDE and click **Open Anyway**, then confirm with your password or Touch ID. (On older macOS versions, right-click DECIDE and choose **Open** instead.) You only need to do this once.
- **Windows:** unzip the file and run `DECIDE.exe`. If SmartScreen appears, choose **More info**, then **Run anyway**. The Microsoft WebView2 runtime is required (included in Windows 11).

Models and autosaves are stored in `~/DECIDE/app/models` and `~/DECIDE/app/autosave`. To run the app from source, see `app/README.md`.

## Install

```bash
git clone <repository-url>
cd decide-engine
pip install -e .          # editable install is required (NMA priors are read from ./priors)
pip install -e ".[dev]"   # adds pytest and the Word/image report dependencies
```

Python 3.10+, numpy, scipy, pandas, openpyxl. Word (.docx) reports and report figures additionally need `python-docx` and `pillow` (`pip install -e ".[docx]"`). Import name: `heor_tree_engine`.

## Tests

```bash
pytest
```

Some NMA tests compare with reference JSON files generated by R packages (scripts in `tests/reference/`).
