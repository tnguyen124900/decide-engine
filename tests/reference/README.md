# Cross-checking the DECIDE NMA engine against R `netmeta`

Purpose: show that DECIDE's frequentist network meta-analysis engine gives the
same results as `netmeta` (the standard R package used in Cochrane and HTA work)
on netmeta's own example datasets.

The reference files are generated by R scripts in this folder and compared with
the Python engine by the tests named below. Network meta-analysis in DECIDE is
currently **experimental**.

## One-time setup and run

All commands are run from the repository root.

1. Install R (https://cran.r-project.org/).
2. Install the required R packages (first time only, takes a few minutes):

   ```bash
   Rscript -e 'install.packages(c("netmeta", "jsonlite"), repos = "https://cloud.r-project.org")'
   ```

3. Generate the reference files:

   ```bash
   Rscript tests/reference/make_netmeta_reference.R
   ```

   Output: `tests/reference/netmeta_*.json` files (smoking cessation OR/RR/RD,
   Franchini 2012 MD, Franchini 2012 SMD with two arms, dietary fat rate ratio).

4. Run the comparison tests:

   ```bash
   python -m pytest tests/test_nma_reference.py -v
   ```

   (If `pytest` is missing: `pip install pytest`.)

## What is compared

| Test | Compared with netmeta | Tolerance |
|---|---|---|
| `test_effects_*` (6 datasets) | TE, seTE (fixed and random), tau^2, Q, df | 1e-5 |
| `test_prediction_intervals_match_netmeta` | random-effects prediction intervals | 1e-4; on a mismatch the message says which degrees of freedom netmeta used |
| `test_pscores_match_netrank` | P-scores (`netrank`, `small.values = "desirable"`) | 1e-4 |
| `test_node_splitting_matches_netsplit` | direct, indirect, SE and p from `netsplit` (fixed and random) | 1e-4 |
| `test_design_by_treatment_matches_decomp_design` | Q total / within / between, within-design tau^2, Q between after tau^2 | 1e-5 |
| `test_contribution_matrix_matches_netcontrib_shortest_path` | contribution matrix from `netcontrib(method = "shortestpath")` | 0.02 (the shortest-path split can differ slightly when several paths tie) |

## If a test fails

Small differences are often down to definitions (for example the degrees of
freedom used for prediction intervals, or how flow is split between paths)
rather than errors. If you see a failure, please open an issue and include the
full pytest output.

## Not comparable with netmeta

- Bayesian NMA (exact likelihood): needs `gemtc` or `multinma` with JAGS/Stan.
  See the Bayesian section below.
- CINeMA: checked by hand against the CINeMA web app on a published network.
- Funnel plot / Egger: netmeta does not output numbers for the adjusted Egger
  comparison; checked by simulation instead.

## Component NMA (netcomb)

```bash
Rscript tests/reference/make_netcomb_reference.R
python -m pytest tests/test_nma_components_reference.py -v
```

Compares component effects (random and common), tau^2, additive Q, Q difference
and df of DECIDE's additive model (`nma_components.run_component_nma`) with
`netmeta::netcomb` on 9 fixed contrasts (declared identically in R and Python).

## Bayesian (gemtc / BUGSnet)

```bash
Rscript tests/reference/make_gemtc_reference.R      # requires JAGS
Rscript tests/reference/make_bugsnet_reference.R
python -m pytest tests/test_nma_bayes_reference.py -v
```
