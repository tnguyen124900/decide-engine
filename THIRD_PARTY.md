# Third-party material

This repository contains **code only**.

- `samples/` holds models that reproduce **published** studies (Krijkamp et al., Med Decis Making 2018 Sick-Sicker; Alarid-Escobar et al., arXiv:2108.13552 time-dependent Sick-Sicker; Cai et al., Front Oncol 2021 KEYNOTE-189 pembrolizumab; Nguyen & Mital, PharmacoEconomics 2025 capivasertib, the maintainer's own study), with the source cited inside each file, so the engine can be checked against the published results. All rights in the original publications remain with their authors and publishers.
- `tests/reference/` has R scripts that regenerate reference results from the `gemtc`, `netmeta` and `bugsnet` packages (not included; install them from CRAN/GitHub).
- Methods follow published guidance and the literature; the documentation cites them by name only.
