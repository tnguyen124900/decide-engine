# Contributing

Bug reports and pull requests are welcome.

1. Fork, then `pip install -e ".[dev]"`.
2. Run `pytest -q` before you open a pull request. Add a test for every change in behaviour.
3. For a new model feature, include a check against a published result or an independent implementation whenever one exists, and say which in the pull request.
4. By contributing you agree that your contribution is released under the MIT license of this repository.

Please report security problems privately using GitHub's *Report a vulnerability* button on the repository's Security tab, rather than in a public issue.
